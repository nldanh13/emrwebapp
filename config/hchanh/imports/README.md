# Nguồn kiểm hồ sơ nội bộ

Đặt file CSV đã xuất từ nguồn được kiểm soát trong thư mục này, sau đó cấu hình:

```json
{
  "enabled": true,
  "source_file": "records_check.csv",
  "spreadsheet_url": "",
  "auto_sync_on_open": false
}
```

Không đặt thư mục này trong vùng chia sẻ công khai. Không commit file CSV có dữ liệu người bệnh.
